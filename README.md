# Matrix Operations in C

## 📌 About the Project

This project is a menu-driven C program that performs basic matrix operations using **functions and 2D arrays**. It helps demonstrate how matrices can be manipulated in the C programming language.

## ✨ Features

- **Matrix Addition:** Adds two matrices of the same dimensions.
- **Matrix Multiplication:** Multiplies two matrices when their dimensions are compatible.
- **Matrix Transpose:** Converts rows into columns and columns into rows.
- **Menu-Driven Interface:** Allows users to choose an operation.
- **Input Validation:** Checks matrix dimensions before performing operations.

## 🛠️ Technologies Used

- C Programming Language
- 2D Arrays
- Functions
- Loops and Conditional Statements

## ⚙️ Requirements

- A C compiler, such as GCC
- Visual Studio Code, Code::Blocks, or another C development environment

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/matrix-operations-c.git
   ```

2. Navigate to the project directory:

   ```bash
   cd matrix-operations-c
   ```

3. Compile the program:

   ```bash
   gcc matrix_operations.c -o matrix_operations
   ```

4. Run the program:

   **Windows:**
   ```bash
   .\matrix_operations.exe
   ```

   **Linux/macOS:**
   ```bash
   ./matrix_operations
   ```

## 📖 How to Use

When you run the program, a menu appears:

1. Matrix Addition
2. Matrix Multiplication
3. Matrix Transpose
4. Exit

Enter your choice and follow the instructions to enter the matrix elements.
